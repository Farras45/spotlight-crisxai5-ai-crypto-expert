A spotlight entry for make.fun's "Spotlight @crisxai5: AI & Crypto Expert on X" bounty: an original, phone-readable graphic introducing @crisxai5 (Cris XAI) as a must-follow AI and crypto expert covering AI agents, crypto insights, and Web3 innovation. The graphic (`spotlight.png`, 1024×1024) is published in a public X post whose text carries @crisxai5, the profile link, hashtags, and a make.fun play code; places go by the post's likes + reposts + quotes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` (the posted X post's address) from this repository to `/output/POST.json`, where the gate reads it.
